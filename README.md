## The Heirloom guarantee, briefly

Memophant is shipped under **The Heirloom License, Version 1.0**, variant
`HL-1.0-MPL2.0-12mo`. While the developer is active, Memophant is a normal
paid product with a private source repository. If the developer goes 12
months without a maintenance signal **and** doesn't respond to a good-faith
support request within 90 days, the source code is automatically released
under MPL-2.0 — irrevocably, for everyone, forever.

The mechanical "publicly verifiable signal of continued maintenance"
required by License Section 4(a) is recorded as signed commits to
[`heartbeat.log`](heartbeat.log) in this repository. A monthly cron and
every release publish a new entry; if you ever see the log going stale,
that's the first warning. Section 4(b)'s support contact is
<mailto:hello@memophant.co>.
